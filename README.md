# KONNEKT

KONNEKT is a React + Vite social-app project.

## Run locally

```bash
npm install
npm run dev
```

## Build for GitHub Pages

```bash
npm run build
```

The Vite base path is configured as `/KONNEKT/` for the repository's GitHub Pages URL.

## Current development status

This repair consolidates the app into one navigation system and automatically discovers `.js` and `.jsx` screen files in `src/screens`.

The existing screens currently contain a mixture of sample content, local-only interactions and placeholder flows. They are not yet a production messaging, video-upload, calling or authentication backend. Real multi-user features require backend configuration, security rules, storage and end-to-end testing. Keep the project on free-tier services and do not enable paid billing without explicit approval.
